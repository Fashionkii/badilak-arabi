# فحوص قديمة محفوظة للرجوع إليها

هذه الملفات الـ21 كانت تحمي قرارات معتمدة وقت كتابتها: كل واحد منها يقارن الموقع بنسخة محددة من المستودع في أكتوبر وأوائل نوفمبر 2026، ويفشل إذا اختلف ملف محمي عن تلك النسخة.

الموقع تغيّر بعدها بقرارات لاحقة معتمدة (النصوص، البيانات، التصميم، التنقل)، فصارت كلها تفشل على `main` من قبل 16 نوفمبر 2026، وبقاؤها بجوار الفحوص الحية كان يخفي أي فشل جديد وسط فشل قديم معروف.

- لم يُحذف شيء ولم يُغيَّر منطق أي فحص. عُدّلت مسارات الملفات فقط لتناسب المجلد الجديد، وكل ملف يفشل بعد النقل بالرسالة نفسها التي كان يفشل بها قبله.
- للتشغيل من جذر المستودع: `node scripts/legacy/<الاسم>.cjs`. تحتاج سجل git كاملًا؛ في نسخة مختصرة (shallow) تفشل بخطأ `git show` لا بنتيجة الفحص.
- إحياء أي فحص يعني مراجعة ما يحميه واحدًا واحدًا، ثم تحديث نسخة المقارنة إلى التزام حديث معتمد. لا يُحدَّث الأساس آليًا: ذلك يجعل الفحص ينجح دون أن يحمي شيئًا.

الفحوص الحية تُشغَّل بأمر واحد: `node scripts/check.cjs`.
