## ما تغير

- بحث محلي محدود، بلا API أو خدمة مدفوعة: توحيد الهمزات والتشكيل والتطويل والمسافات، ومطابقة كلمات العبارة دون اشتراط ترتيبها. كلمات مساعدة تحريرية لـ13 موردًا، مثل كتاب/كتب وطفل/أطفال ووظيفة/وظائف. أسماء الموارد أولًا، ثم الكلمات الأقرب، مع ثبات ترتيب النتائج المتعادلة. بقيت تصفية القسم والمنشأ والبلد قبل البحث، وبقي ترتيب الاستكشاف كما هو عند غياب البحث.
- تجنب تعميم كلمة من عنوان قسم واسع على كل موارده: البحث عن الكتب لا يُظهر ألعابًا لمجرد وجودهما في قسم الثقافة. هذه مطابقة محدودة، وليست فهمًا لغويًا عامًا أو محرك توصية أو إثباتًا لتكافؤ الموارد.
- رسالة غياب النتائج تنسب الغياب للعبارة والتصفية الحالية؛ لا تستنتج غياب مورد موثق. زر «عرض الكل» ووظيفته محفوظان.
- البحث ظاهر وله تسمية مرتبطة بالحقل؛ لم يعد يُطوى عند تغيير القسم أو الرجوع.
- تاريخ الإعداد مسجل لكل تمرين معروف التاريخ:47 بتاريخ18 أكتوبر، وأربعة بتاريخ19 أكتوبر: المعاني، دبي للمستقبل، Kezakoo، TelmidTICE. لا تاريخ جديدًا مخترعًا لتمرين كرنك الأقدم. تواريخ مراجعة الموارد نفسها لم تتغير. دليل الدفعتين: [تمارين18 أكتوبر](PRACTICAL-TRIALS-20261018.md)، و[إضافات19 أكتوبر](LEARNING-ACTIONS-2026-10-19.md).
- توضيح نص هنداوي حول إتاحة العنوان وبيانات الطبعة والترجمة وحقوق إعادة الاستخدام، والتمييز بين إنشاء حساب ودفع اشتراك. هذا تصحيح للالتباس، وليس إثباتًا أن النص السابق كان يدعي رسومًا فعلية.
- تخفيف إطار شعار الرئيسية وخلفيات الاختيارات، وإتاحة تدفق رأسي طبيعي ومسافات أوضح. نفس الصور والشعار والمداخل الاثنا عشر والروابط والأقسام.
- تفاصيل المورد تعرض التعريف والتنبيه والحقائق وتاريخ مراجعة المورد وزر الزيارة، ثم التمرين الاختياري والمادة المرتبطة والتفاصيل الموسعة والمقارنة. لم تختفِ المصادر أو التنبيهات داخل تمرين مطوي.

- التمارين الـ52 مطوية في البداية بدل فتحها. يمكن فتحها بلوحة المفاتيح أو النقر؛ نصها وخطواتها محفوظة.

## فصل مراجعة الكود عن مراجعة المعنى

مراجعة الكود تحصر الفرق في البحث وتاريخه التحريري وعرض التفاصيل وتنسيق المعاينة. مراجعة المعنى تقارن بيانات الكتالوج، والكروت، والتحذيرات، والمقارنات، ووجهات الروابط وإجراءاتها؛ وتسمح فقط بصياغة هنداوي وفصل تاريخ الإعداد وعبارة غياب النتائج. الترتيب والطي تغييران سلوكيان معلنان، وليس مجرد تجميل.

قبل الاعتماد نقيّم: هل يصل الزائر للمورد والقيد أسرع؟ هل ما زال يجد التمرين بسهولة؟ هل الظاهر من البحث كافٍ على الهاتف؟ نتائج المراجعة قد ترجح الإبقاء على موضع التمرين الجديد مع تغيير حالة فتحه، دون الرجوع عن الإصلاحات المستقلة.
