- نفس صورة الفضاء والشعار المعتمدين، مع تقليل ظهور الخلفية إلى 24%، وسطح داكن أهدأ خلف مقدمة الرئيسية، وأسطح قراءة معتمة. لا صورة جديدة أو خدمة أو تحميل إضافي.
- هوامش داخلية متناسقة للمقدمة و«ابدأ بما تعرفه»، وعمود ثابت للأيقونة داخل أزرار المجالات. روجعت صورتا المستخدم بالفعل بعد العثور على نسختيهما المحلية.
- صفوف مشتركة بين كروت كل صف بواسطة CSS subgrid: الهوية، البلد، السياق، الملاءمة، الفائدة، التحذير، الأزرار. تبقى النصوص كاملة؛ الأطول يوسّع الصف. يحتفظ المتصفح القديم بتنسيق Flex السابق.
- زر وجهة الدليل يعرض نافذة قصيرة: الانتقال للموقع الخارجي في تبويب جديد، أو مراجعة البدائل الموجودة، أو متابعة التصفح. عندما لا توجد مقارنة، يوجّه للتفاصيل والقيود بدل اختراع بدائل. المقارنة تستخدم المحتوى الحالي؛ لا بيانات أو ترشيحات جديدة.
- الإغلاق بـEscape يعيد التركيز للزر، ومراجعة البدائل تفتح المقارنة الحالية داخل التفاصيل. روابط المصادر والمقالات والإعلانات ومصادر التعلم خارج نطاق اعتراض زر الدليل، وصفحات الخدمة المستقلة تحتفظ بالرابط المباشر.
