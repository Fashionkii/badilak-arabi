# إدارة صور المقالات والمشاركة

الموقع الحالي ثابت، ولا يحتوي على باك إند أو لوحة إدارة منشورة. لا تمثل هذه الإضافة نظام إدارة محتوى أو رفع صور من المتصفح.

- المصدر الموحد: `data/article-media.json`، مدخل لكل مقال موجود.
- `socialTitle`: عنوان مختصر للمشاركة فقط؛ عنوان المقال الأصلي والنص التحريري محفوظان.
- `alt`: وصف دقيق للصورة لقارئ الشاشة وبيانات المشاركة.
- `photo`: مسار صورة محلية داخل `images/`؛ ضع الصورة التي تختارها يدويًا وحدّث المسار.
- `source`, `credit`, `license`, `licenseUrl`: مصدر الصورة وترخيصها. الصور الأولية من Unsplash، مخزنة محليًا؛ لا يعتمد عرض الموقع على خدمة الصور الخارجية.
- `focalPoint`: موضع مركز الاقتصاص، قيمتان بين 0 و1.
- `customFields`: حقول نصية اختيارية، تظهر داخل المقال بعد الصورة. القيم تُهرب قبل العرض، ولا تسمح بتنفيذ HTML.
- يمكن إبقاء `photo` فارغًا لمقال جديد: يولّد النظام بطاقة نصية آليًا إلى حين اختيار صورة مناسبة. اختيار صور من نتائج Google ليس تلقائيًا؛ يجب التحقق من الترخيص والموضوع.

بعد التعديل شغّل:

```bash
python -m pip install -r scripts/article-media-requirements.txt
python scripts/build-article-media.py
```

يتطلب توليد العربية Pillow مع دعم RAQM وخطًا عربيًا. يستخدم السكربت DejaVu Sans على Linux؛ لتحديد خط آخر:

```bash
python scripts/build-article-media.py --font /path/to/ArabicFont.ttf
```

ينتج السكربت صورة غلاف WebP بمقاس 1200×675، وبطاقة اجتماعية JPEG بمقاس 1200×630. يحدّث OG وTwitter وصورة Article JSON-LD وصور بطاقات صفحة المقالات. توليد الصور آلي؛ نشر التغييرات يتم بالطريقة الحالية عبر Git/Vercel.

المشاركة تستخدم رابط المقال نفسه، مثل `/guides/arabic-ai`، لا رابط الرئيسية لكل حملة. بيانات الصورة موجودة في HTML المقدم مباشرة، وليست مضافة بواسطة JavaScript. بعض المنصات تحفظ معاينة قديمة؛ قد تحتاج إعادة جلب الرابط في أدوات المنصة. لا يمكن ضمان عرض المعاينة كاملة في كل موضع إعلاني؛ بعض المواضع تقتص الصورة، لذا يجب اختبار معاينة الإعلان المختار وتحميل صورة الإعلان مباشرة عند الحاجة.

لا توجد في هذا التعديل مفاتيح Meta أو تتبع جديد أو AdSense أو خدمة خلفية. إنشاء لوحة آمنة لإدارة المحتوى عبر الإنترنت مرحلة مستقلة، تشمل تسجيل دخول وصلاحيات وتخزين ورفع ونشر.
