# بديلك عربي — Design Lab Handoff

الحالة: **مسار جانبي غير معتمد للنشر**.

## الغرض
تجميع مخرجات الاستكشاف البصري في نسخة جانبية قابلة للمعاينة والنقل، بدل بقاء القرار موزعًا بين Figma وCanva وMagicPath وLovable وWhimsical وtldraw.

## مصدر الحقيقة حسب الطبقة
- **Copy / Data / Links / Behavior:** ملفات الموقع الحالية على الفرع الأصلي الذي أنشئت منه النسخة.
- **Visual exploration:** `css/design-lab.css` و`design-lab.html`.
- أدوات التصميم الخارجية: مراجع استكشاف فقط؛ لا تُنقل نصوصها تلقائيًا.

## حدود هذا الفرع
- لا يغيّر بيانات الدليل.
- لا يغيّر روابط المنتجات أو المصادر.
- لا يغيّر وظائف البحث أو الفلاتر أو الرحلات.
- لا يعلن تفعيل AdSense أو Affiliate.
- يحافظ على مواضع المعاينات التجارية الموجودة.
- لا يعتمد لوجو جديد؛ اتجاهات العلامة داخل المعمل للمقارنة فقط.

## الملفات الجديدة
- `css/design-lab.css`: طبقة بصرية قابلة للإزالة بالكامل.
- `design-lab.html`: مكتبة أصول/حالات منفردة داخل نسخة شغالة.
- `docs/DESIGN-LAB-HANDOFF-2026-10-08.md`: هذا الملف.

## التنفيذ اللاحق
عند نقل عنصر معتمد إلى `main`:
1. انقل أصغر نطاق ممكن.
2. لا تنقل Copy/Data/Behavior من المعمل.
3. قارن Code Diff.
4. قارن Semantic Diff.
5. اختبر 390 و768 و1440 على الأقل.
6. اختبر مسار الرجوع، البحث، الفلاتر، الروابط الخارجية، ومواضع الإعلانات المرتبطة بالجزء المتغير.
