# بديلك عربي — Responsive / RTL / Interactions

## أحجام المراجعة
- 360px: حد هاتف ضيق.
- 390px: هاتف مرجعي.
- 768px: Tablet / انتقال.
- 1440px: Desktop واسع.

الـCSS التجريبي يستخدم حاليًا نقاط انتقال 760px و900px. بعض CSS المقالات التاريخي يستخدم 650px؛ لا يُعاد تنظيمه داخل هذه الجولة إلا عند نقل التصميم النهائي بصورة نظيفة.

## RTL
- `dir="rtl"` هو البداية وليس النهاية.
- اتجاه الأسهم يجب أن يعبّر عن الفعل الحقيقي.
- الأرقام وأسماء المنتجات الإنجليزية تستخدم Bidi مناسبًا عند الحاجة.
- Search، Tabs، Detail facts، Badges، Modal وBreadcrumb-like العودة تُراجع بصريًا بالعربية.
- لا تُقلب شعارات الشركات.

## Navigation
- Desktop: الروابط الرئيسية ظاهرة ومضغوطة.
- Mobile: يمنع التزاحم أو overflow الأفقي غير المقصود.
- المسار الحالي يمكن تمييزه بالـborder/background مع نص واضح.

## Keyboard
- كل رابط/زر/حقل قابل للوصول بالـTab.
- Focus-visible واضح بحد Gold مناسب.
- Modal يجب أن يظل قابلًا للإغلاق من عنصر واضح؛ لا تُغيّر آلية السلوك الحالية في هذه الجولة.

## Hover / Active
- Hover بسيط، بدون حركة تشتت.
- Active/Selected أوضح من Hover.
- `prefers-reduced-motion` يلغي الحركة غير الضرورية.

## Loading / Empty / Error
- Loading لا يحجب بنية الصفحة بالكامل.
- Empty يشرح الخطوة التالية: غيّر الفلتر أو البحث.
- Error لا يوحي بفقد البيانات، ويعطي إعادة المحاولة عند وجودها وظيفيًا.

## Return paths
رحلات الرجوع الحالية محفوظة. أي نقل من التصميم التجريبي لا يجوز أن يكسر:
- المقال ← النتائج ذات الصلة.
- التفاصيل ← المجال.
- المسار من خدمة مألوفة ← نتائج ذات صلة.

## External links
الانتقال الخارجي يظل مميزًا عن القراءة أو التفاصيل، ولا تُغيّر روابطه أو مصادره ضمن نقل بصري.
