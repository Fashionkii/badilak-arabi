# استيراد حزمة بديلك عربي إلى Penpot

1. أنشئ ملفًا جديدًا باسم **بديلك عربي — Visual Master**.
2. من Tokens افتح Tools → Import.
3. استورد `badilak.tokens.json`.
4. أنشئ الصفحات بالترتيب الموجود في `PENPOT-MASTER-MAP.md`.
5. اسحب ملفات SVG من `boards/` إلى الصفحات المناظرة.
6. اسحب الأصول المطلوبة من `images/brand/` و`images/visual/`.
7. اربط ألوان ومسافات العناصر بالـTokens المستوردة.
8. حوّل العناصر المتكررة فقط إلى Components.
9. لا تنقل Copy أو Data من ملف التصميم إلى الموقع.
10. لا تعتبر أي لوجو أو Layout معتمدًا حتى يراه المستخدم ويعتمده صراحة.

## قاعدة النقل إلى الكود
بعد الاعتماد:
- انقل أصغر جزء ممكن.
- لا تنقل `design-lab.css` ككتلة كاملة.
- أعد تطبيق القرار المعتمد داخل CSS/Components الأصلية.
- راجع Code Diff وSemantic Diff.
